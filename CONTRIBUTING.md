# Участие в разработке

Спасибо, что хотите помочь! Проект — монорепозиторий в папке `throne-clash/`; все команды выполняются из неё.

## Быстрый старт

```bash
pnpm install
pnpm db:up && pnpm db:generate && pnpm db:migrate   # или pnpm db:embedded без Docker
pnpm dev                                            # сервер :3000, сайт :5173
```

Подробности и решение типичных проблем — в [`README.md`](README.md).

## Перед коммитом

```bash
pnpm lint && pnpm format:check && pnpm typecheck
TEST_DATABASE_URL=postgresql://... pnpm test:coverage   # тесты чистят БД: берите отдельную
pnpm test:e2e                                           # Playwright (нужен chromium)
```

CI запускает те же проверки и не пропустит слияние с красными тестами. Покрытие ядра (`packages/shared`, расчёты замка и боя) — не ниже 80 %.

## Правила кода

- TypeScript строгий, **без `any`**; ввод извне проходит через Zod (схемы — единственный источник типов запросов).
- Сервер авторитетен: клиент не решает исходы. Формулы живут в `packages/shared` и остаются чистыми функциями (время и случайность передаются параметрами, `Date.now()`/`Math.random()` в них нельзя).
- Каждое изменяющее действие идёт через `RealmRunner.mutate` (расчёт → действие → запись в одной транзакции, `Idempotency-Key`).
- Новое хранилище — интерфейс + реализация на Prisma + in-memory, и **один общий набор тестов** для обеих реализаций.
- Тексты интерфейса — в i18n (`ru` и `en`), сервер отдаёт коды ошибок, а не строки.
- Доступность: интерактивные элементы с названиями, фокус виден, контраст AA; проверки `@axe-core/playwright` не должны краснеть.
- Секретов в репозитории нет: только `.env.example` с пустыми значениями или очевидными заглушками.
- Значимые архитектурные решения записывайте в [`docs/DECISIONS.md`](docs/DECISIONS.md) (следующий номер `D-NN`).

## Коммиты

[Conventional Commits](https://www.conventionalcommits.org/ru/): `feat(server): …`, `fix(web): …`, `docs: …`, `test: …`, `chore: …`. Их проверяет commitlint (hook husky). Одна логическая правка — один коммит.

## Запрос на слияние

Опишите **что и зачем**, как проверили, приложите снимок экрана для изменений интерфейса (375 px и 1440 px). Шаблон подставится сам. Обновите документацию и `CHANGELOG.md` (раздел `Unreleased`).

## Баланс и режим бога

Числа баланса лежат в `packages/shared`; изменение баланса — это изменение правил игры, обсуждайте его в задаче до кода. Действия режима бога всегда должны попадать в журнал аудита — не добавляйте «тихих» действий.

Участвуя, вы соглашаетесь с [Кодексом поведения](CODE_OF_CONDUCT.md); код принимается под лицензией [MIT](LICENSE). Об уязвимостях — [`SECURITY.md`](SECURITY.md), а не публичные задачи.
